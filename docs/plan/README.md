# 计划文档

存放一切"排期与进度"类文档:总体开发计划、迭代计划、迁移计划等。

与其他目录的分工:**架构文档说"怎么做是对的",计划文档说"什么时候做、做到什么程度算完"。** 验收标准写在计划里,设计规格写在 `modules/` 里,两边互相引用不重复。

## 索引

| 文档 | 内容 | 状态 |
|---|---|---|
| [development-plan.md](development-plan.md) | 框架开发总计划:里程碑 M0~M6、任务分解、验收标准、风险 | active |
| migration-plan.md | 现有项目迁移计划(M1 完成、启动迁移时编写) | 未创建 |

## 规则

- 计划是活文档:任务完成勾选对应项,里程碑状态变化更新总览表
- 排期变更直接改文档,重大调整(砍掉/新增里程碑)在文档头部留一行变更记录
- 单个迭代/专项(如"AdMob 真机联调")工作量超过 3 天的,单独建一篇计划文档并登记到上表
